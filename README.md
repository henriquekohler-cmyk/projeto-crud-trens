# 🚆 CRUD Trens

Um sistema web simples e eficiente desenvolvido para gerenciamento e simulação de frota ferroviária.

---

## 🚀 Funcionalidades

* ➕ **Cadastro de Trens:** Adicione novos trens informando modelo, capacidade e status operacional.
* 📋 **Listagem Completa:** Visualize toda a frota cadastrada com informações detalhadas.
* ✏️ **Edição de Dados:** Atualize as informações dos trens através de um formulário interativo.
* 🗑️ **Exclusão:** Remova registros do sistema de forma rápida e segura.
* ⚙️ **Simulador:** Simulação dinâmica de operação e tráfego ferroviário.

---

## 🛠️ Tecnologias Utilizadas

* **Backend:** PHP
* **Frontend:** HTML5, CSS3
* **Banco de Dados:** MySQL (XAMPP)
* **Servidor Local:** Apache
